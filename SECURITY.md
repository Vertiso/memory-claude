# Security policy

Vertiso supports the latest published version of the Vertiso Memory plugin.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
through this repository's **Security and quality → Advisories → Report a
vulnerability** flow. If that flow is unavailable, email
support@vertiso.ai with `Security` in the subject.

Include the affected client and plugin version, impact, reproduction steps,
and sanitized logs. Never include tokens, credentials, or real memory contents.

Full security and responsible-disclosure guidance:
https://memory.vertiso.ai/security.

For account access, OAuth, deletion, billing, or general product help, use
https://memory.vertiso.ai/support.
